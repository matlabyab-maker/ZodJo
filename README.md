## Important
This generator creates and updates the project source files.
It does not build an APK.

The current Python entry point is a Kivy-based prototype.
Android system-wide DNS, native floating mouse control, and
site-specific Send/File automation require additional implementation
and platform permissions; they are not claimed as completed.

The GitHub workflow is a source validation workflow, not an APK build.
No GitHub repository address or access token is hard-coded.
